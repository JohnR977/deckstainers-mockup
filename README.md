# deckstainers-mockup

A turnkey website + simple CRM for **Stain & Seal Supply Pro Partners**: one- and two-man deck staining crews.
This mockup is set up as **deckstainers.com** for a fictional Chattanooga company, plus a second fictional
Knoxville company to prove the swap.

## How it works

Plain HTML/CSS/JS, generated by a small Node script with **no dependencies**. Output goes to `docs/`, which GitHub Pages serves.

```
site.config.json              ← the Chattanooga partner (everything swappable lives here)
configs/knoxville.config.json ← a second partner, same code
content/<city>/areas.json     ← each partner's local service-area copy (must be unique per city)
content/sources.json          ← every cited fact links to one of these
src/build.mjs                 ← builds a whole site from one config
src/content/*.mjs             ← page templates and copy
src/assets/                   ← CSS, JS (calculator, visualizer, dashboard), images
docs/                         ← built site (Chattanooga) — GitHub Pages root
docs/demo-knoxville/          ← built site (Knoxville demo)
tools/                        ← audit script, teaser-image renderer
```

## Commands

```bash
npm run build      # builds both sites into docs/ and docs/demo-knoxville/
npm run serve      # http://localhost:8080
node tools/audit.mjs docs                 # broken links, alt text, titles, JSON-LD
node tools/audit.mjs docs/demo-knoxville
```

Requires Node 18+. (`tools/render-teaser.py` needs Python 3 with Pillow, and only matters if you change stain colors.)

## Adding a new Pro Partner

1. Copy `configs/knoxville.config.json` to `configs/<city>.config.json` and change the business, theme colors, prices, warranty, stains, photos and `areaGroups`.
2. Write `content/<city>/areas.json`: one entry per service area, with **real, different local copy**. The build warns if two areas look copy-pasted.
3. `node src/build.mjs configs/<city>.config.json docs/demo-<city>` (or a separate repo/domain for a live partner).

Any value written as `{"value": ..., "sample": true}` shows a **SAMPLE** tag on the site until it's replaced.

## Going live (per partner)

- Set `"mockup": false`. This removes `noindex`, the demo bar and the "stored in your browser" notes, and switches canonical URLs to `launchUrl`.
- Replace every SAMPLE value and every stock photo (see `REPORT.md` → "Replace before launch").
- Connect forms to a real backend (see `CRM_PLAN.md`).
