# deckstainers-mockup

A turnkey website + simple CRM for **Stain & Seal Supply Pro Partners**: one- and two-man deck staining crews.
This mockup is set up as **deckstainers.com** for a fictional Chattanooga company, plus a second fictional
Knoxville company to prove the swap.

- **Marketing / changing words, photos, colors, fonts, logo:** [`MARKETING_GUIDE.md`](MARKETING_GUIDE.md)

## How it works

Plain HTML/CSS/JS, generated by a small Node script with **no dependencies**.

**Everything a partner can change lives in their folder.** Code never holds wording, photos or brand settings.

```
partners/chattanooga/
  site.config.json   ← every word on every page, photo names, colors, fonts, logo, prices, areas, articles, sources
  images/            ← every picture (and the logo file)
  crm.config.json    ← dashboard settings (demo login, re-coat timing). Not marketing.
partners/knoxville/  ← a second, fictional partner: same code, different folder (image logo, other fonts)

src/build.mjs        ← builds a whole site from one partner folder
src/check.mjs        ← checks a partner folder and explains mistakes in plain English
src/content/pages.mjs← page layouts (no wording in here)
src/lib/             ← page shell, text formatting ({city}, **bold**, [links](/page/), {cite:key})
src/assets/          ← CSS and JS (calculator, visualizer, tint, dashboard)
docs/                ← built Chattanooga site (+ docs/demo-knoxville/) for local preview
.github/workflows/deploy.yml ← on every push: check → build → publish to GitHub Pages
tools/audit.mjs      ← broken links, alt text, titles, JSON-LD
```

## Commands

```bash
npm run check      # checks every partner folder for mistakes
npm run build      # builds both sites into docs/ and docs/demo-knoxville/
npm run serve      # http://localhost:8080
npm run audit      # broken links, alt text, titles, JSON-LD
```

Requires Node 20+.

## Adding a new Pro Partner

1. Copy `partners/knoxville/` to `partners/<city>/`.
2. Change `business`, `brand`, `location` (with real NOAA climate numbers), `areas`/`areaGroups` (with **real, different local copy**; the checker warns about copy-paste pages), prices and photos. Follow `MARKETING_GUIDE.md`.
3. `npm run check`, then `node src/build.mjs partners/<city> docs/demo-<city>` (or its own repo/domain for a live partner).

Any value written as `{"value": ..., "sample": true}` shows a **SAMPLE** tag on the site until it's replaced.

## Going live (per partner)

- Set `"mockup": false`. This removes `noindex`, the demo bar and the "stored in your browser" notes, and switches canonical URLs to `launchUrl`.
- Replace every SAMPLE value and every stock photo (see `REPORT.md` → "Replace before launch").
- Connect forms to a real backend (see `CRM_PLAN.md`).
